Swim Guide Platform 是一个面向大学生及游泳初学者的智能游泳服务平台，旨在解决许多学生不会游泳、缺乏系统学习资源以及泳池服务信息获取困难等问题。项目以广州大学城泳池场景为切入点，结合真实游泳场馆运营需求，提供场馆展示、游泳知识科普、教学内容管理、用户咨询与服务连接等功能。

平台计划采用前后端分离架构开发，前端基于 Vue 3 + TypeScript，后端采用 FastAPI 构建 RESTful API，并使用数据库管理用户需求、文章内容、视频资源及场馆信息。项目后续将逐步扩展微信小程序、公众号内容管理以及智能化服务能力。

在 AI 方向，项目计划接入 DeepSeek API，结合游泳知识库与检索增强生成（RAG）技术，开发智能游泳学习助手，为用户提供个性化学习建议、动作问题分析、训练计划推荐以及常见问题解答。同时，通过数据分析用户需求和内容反馈，帮助游泳馆优化宣传策略和服务体验。

该项目不仅是一个软件工程实践项目，也是一次探索校园体育服务、内容运营与人工智能技术结合的产品实践。
