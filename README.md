# Swim Guide Platform 🏊

一个面向大学生及游泳初学者的智能游泳服务平台。

## 项目背景

许多大学生需要完成游泳相关课程或测试，但缺少系统学习资源和可靠训练渠道。

本项目以广州大学城泳池场景为切入点，连接游泳场馆、初学者和教学内容，通过数字化平台提供：

- 泳池信息展示
- 游泳知识学习
- 视频内容管理
- 用户咨询服务
- AI 智能游泳助手
